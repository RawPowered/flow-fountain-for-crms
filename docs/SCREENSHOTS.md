# Screenshot provenance

[Return to the product tour](../README.md#product-tour)

The documentation images were captured on October 24, 2026 from the clean public
source version of Flow Fountain for CRMs. They show the existing application interface in a
local, isolated browser preview. The preview did not connect to a database,
production installation, or external integration.

| Image | Capture context |
|:---|:---|
| Workflow designer | HAWK interface with a fictional, unpublished source-note review draft. No execution history or external connection. |
| Sentinel overview | SENTINEL interface with synthetic event counts and review statistics. The numbers are demonstration data. |
| Evidence preservation | Preservation interface with a fictional draft CSV definition. No completed delivery or protected job is shown. |
| Python console | PARROT interface with a fictional offline text-normalization example. The bridge is explicitly not connected. |
| Blank installation | The existing installer at its initial database step. User, password, and database name fields are empty. |

Workspace images carry an **Interface preview · fictional data** label. Their API
responses were mocked to make the interfaces viewable without private records.
These captures are not evidence of live database installation, successful
integration calls, or completed preservation operations.

Each final image was visually reviewed for visible personal information,
credentials, deployment domains, and private records before inclusion. Only
the approved PNG files and their SHA-256 hashes appear in the release manifest.
The release check rejects a changed PNG until its reviewed hash is updated.
PNG files are also restricted to the documentation screenshot directory and
checked for their file signature and bounded image dimensions.

The screenshot preview server, browser profiles, logs, and intermediate images
are excluded from the repository and release package. Fictional preview records
are not installed into the application. The header artwork is a separate SVG
project illustration and is not presented as a software screenshot.
